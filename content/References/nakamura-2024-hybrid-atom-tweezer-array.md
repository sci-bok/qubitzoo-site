Demonstrates a dual-isotope ytterbium tweezer array that combines $^{171}$Yb nuclear-spin data qubits with $^{174}$Yb optical-clock ancilla qubits, making the hybrid data/ancilla version of the alkaline-earth clock-qubit architecture concrete.

## Key Results
- Hybrid array with nuclear-spin data qubits and optical-clock ancilla qubits
- 99.1(1.8)% data-qubit coherence retained during 20 ms ancilla-imaging exposure
- Ancilla discrimination fidelity: 0.9992
- Ancilla survival probability: 0.988
- Strong evidence that alkaline-earth clock-style architectures can support low-crosstalk mid-circuit ancilla readout
