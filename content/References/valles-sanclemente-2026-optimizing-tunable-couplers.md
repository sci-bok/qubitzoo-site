Experimentally maps spectator interactions in a five-transmon processor with flux-tunable couplers and shows that the best idle bias depends on which interaction channel matters for the operation being performed.

## Key Results
- Demonstrates high-fidelity, low-leakage CZ gates using unipolar fast-adiabatic flux pulses applied only to the coupler.
- Shows that residual $ZZ$, one-excitation exchange, and two-excitation exchange can each be nulled, but not generally at the same coupler frequency.
- Uses repeated parity checks to expose how spectator-state changes affect processor-level operation.
