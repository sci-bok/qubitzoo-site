Demonstrates a native three-fluxonium CCZ operation using a microwave-driven transmon coupler.

## Key Results

- A 65 ns native CCZ operation reached $99.39(5)\%$ fidelity.
- The operation is locally equivalent to a Toffoli gate and uses a single control pulse.
- Matching this performance with a conventional decomposition would require approximately $99.94\%$ CZ fidelity.
