Introduces boundary constructions for the honeycomb Floquet code using only pairwise checks, enabling practical planar geometries without adding nonlocal connectivity.

## Key Results
- Boundary construction compatible with pairwise-check Floquet schedules
- Parallelogram geometries with modified bulk measurement sequence
- Clarifies how to make finite planar honeycomb patches practical
