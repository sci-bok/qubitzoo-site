Experimental concatenation of five stabilized bosonic cat qubits with an outer distance-5 repetition code in a microfabricated superconducting circuit.

## Key Results
- Phase-flip correction improved with repetition-code distance while bosonic stabilization suppressed bit flips
- Minimum measured logical error per cycle of $1.65(3)\%$ for the distance-5 code
- Demonstrated a cat–transmon noise-biased CX gate for syndrome extraction
