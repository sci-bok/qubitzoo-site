This preprint demonstrates distance-dependent logical-error suppression for rotated surface-code memories on a cloud-accessible IBM Nighthawk r2 processor.

## Key Findings

- Increasing the protected distance from 3 to 6 reduced per-round logical error from $0.53\%$ to $0.24\%$ in Z memory and from $0.52\%$ to $0.22\%$ in X memory under maximum-likelihood decoding.
- Short readout, fused measurement/reset, and an XX echo materially improved syndrome-extraction performance.
- The distance advantage weakened over experiments extending to 150 rounds, indicating persistent correlated-error limits.
