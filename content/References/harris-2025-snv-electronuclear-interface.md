Introduces a zero-field protocol for a $^{117}$SnV⁻ electron-nuclear spin-photon interface integrated with a photonic circuit. Author order was verified against the PDF title page.

## Key Results
- Physical gate fidelity: 97.8%
- Nuclear-memory-transition coherence: $2.5(1.2)$ ms with two decoupling pulses
- Zero-field operation avoids optical phase kickback on the memory subspace
