This paper is the peer-reviewed archival publication of the first experimental AEON qubit demonstration, implemented in a triangular Si/SiGe triple quantum dot using simultaneous exchange pulses.

## Key Results
- Demonstrates an AEON qubit in a triangular Si/SiGe device.
- Calibrates and executes the full single-qubit Clifford gate set with simultaneous, non-commuting exchange control.
- Measures average blind randomized-benchmarking Clifford fidelity $F_{C1} = 99.86\%$.
- Establishes a peer-reviewed AEON single-qubit benchmark, but does not yet report AEON two-qubit entangling gates or direct cavity coupling.
