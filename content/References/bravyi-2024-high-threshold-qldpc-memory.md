Introduces bivariate-bicycle qLDPC memory protocols with degree-6 connectivity, a depth-8 syndrome cycle, and a $0.7\%$ circuit-level threshold in the final peer-reviewed analysis.

## Key Results
- Concrete $[\![144,12,12]\!]$ code using 144 data and 144 ancilla qubits
- Projected preservation of 12 logical qubits for nearly one million cycles at physical error rate $10^{-3}$
- Connectivity graph decomposes into two edge-disjoint planar subgraphs
