This work demonstrates repeated error detection and encoded logical operations in a superconducting distance-2 surface code.

## Key Findings

- Repeatedly stabilized a distance-2 logical qubit with error-detection cycles.
- Demonstrated arbitrary-state initialization, cardinal-basis measurement, and a universal set of logical single-qubit gates.
- Fault-tolerant variants outperformed matched non-fault-tolerant implementations in the reported tests.
