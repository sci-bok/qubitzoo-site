This paper presents repeated error detection and logical-state control on a superconducting distance-2 surface-code logical qubit.

## Key Results
- Repeatedly stabilized a distance-2 surface-code logical qubit using error-detection cycles.
- Demonstrated logical state preparation, measurement in the cardinal Bloch bases, and a universal set of encoded single-qubit gates.
- Reported that fault-tolerant variants of the tested logical operations outperformed matched non-fault-tolerant implementations.
