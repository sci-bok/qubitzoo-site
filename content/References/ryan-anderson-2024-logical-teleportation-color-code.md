First fault-tolerant logical teleportation circuits for the planar [[7,1,3]] color code on Quantinuum H2, including transversal and lattice-surgery variants.

## Key Results
- Logical process fidelity (transversal teleportation): 0.975 ± 0.002
- Logical process fidelity (lattice-surgery teleportation): 0.851 ± 0.009
- Knill-style logical teleportation/QEC circuit fidelity: 0.989 ± 0.002
