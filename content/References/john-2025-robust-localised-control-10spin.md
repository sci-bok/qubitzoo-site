Major array-control milestone for germanium hole-spin qubits. Demonstrates a two-dimensional 10-spin array with single-qubit fidelities above 99% and analyzes how occupancy tuning improves control locality and suppresses crosstalk.

## Key Results
- Two-dimensional 10-spin germanium array
- Single-qubit gate fidelities above 99%
- Uniform qubit properties across the array despite strong hole-spin anisotropy concerns
- Three-hole operation improves control locality and reduces nearest-neighbor crosstalk
- Rabi frequencies consistently above 1.45 MHz/(mV·T)
