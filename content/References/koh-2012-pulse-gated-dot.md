Develops nonadiabatic pulse-gated control for the three-electron quantum-dot hybrid qubit.

## Key Results
- Uses level anticrossings to decompose logical control into fast charge-like transitions.
- Provides closed-form one- and two-qubit pulse sequences with sub-nanosecond elementary steps.
- Treats a three-electron double quantum dot, not a triple-dot device.
