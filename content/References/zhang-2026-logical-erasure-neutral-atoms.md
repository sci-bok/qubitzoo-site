Demonstrates erasure-aware logical circuits with metastable $^{171}\mathrm{Yb}$ nuclear-spin qubits, using mid-circuit erasure information actively rather than only for post-selection.

## Key Results
- $[[4,2,2]]$ logical encoding with erasure correction during decoding
- Adaptive circuit execution based on mid-circuit erasure information
- Logical teleportation across code blocks with conditionally selected ancillas
