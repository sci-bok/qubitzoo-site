This work uses quantum-error-detection events as the learning signal for reinforcement-learning control of a Willow processor during error-correction experiments.

## Key Findings

- A distance-7 surface code decoded with AlphaQubit2 reached an average logical error per cycle of $7.72(9)\times10^{-4}$ across X and Z memory bases.
- Reinforcement-learning fine-tuning reduced logical error by about 20% after conventional expert calibration.
- Under injected drift, joint control-and-decoder steering improved logical stability by $3.5\times$.
