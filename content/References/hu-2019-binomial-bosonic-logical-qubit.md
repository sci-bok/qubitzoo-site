Repetitive single-photon-loss correction and universal logical control of a binomial bosonic qubit in a superconducting cavity.

## Key Results
- 97% average process fidelity for the universal single-logical-qubit gate set
- Corrected logical lifetime 2.8 times the uncorrected counterpart
- Corrected Ramsey coherence twice the uncorrected value
