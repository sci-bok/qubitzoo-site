Current scaling milestone for germanium hole-spin processors. Demonstrates simultaneous initialization, control, and readout across an extendable 18-qubit Ge array while preserving high single-qubit fidelity and exchange-based multiqubit capability.

## Key Results
- 18-qubit modular germanium array with simultaneous operation across all unit cells
- Average single-qubit gate fidelity: 99.8%
- Median single-qubit gate fidelity: 99.9%
- Characterized nearest-neighbor exchange couplings throughout the device
- Implemented controlled-Z gates and generated a three-qubit GHZ state
