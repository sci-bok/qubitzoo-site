Demonstrates a microwave-activated CZ gate between low-frequency fluxonium qubits, showing that fluxonium-family devices can support fast entangling logic despite very low qubit transition frequencies.

## Key Results
- CZ gate fidelity about 99.2%
- Gate duration 61.6 ns
- Residual ZZ coupling about 46 kHz
- Establishes two-qubit logic viability for the low-frequency fluxonium family
