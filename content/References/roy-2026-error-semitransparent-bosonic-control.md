Universal logical control using dynamic encoding subspaces whose driven trajectories are semitransparent to oscillator photon loss.

## Key Results
- Error-semitransparent logical gate set $\{X,H,T\}$
- Fivefold reduction in gate infidelity conditioned on photon loss
- Extended active-manipulation lifetime under QEC and a composite non-Clifford operation
