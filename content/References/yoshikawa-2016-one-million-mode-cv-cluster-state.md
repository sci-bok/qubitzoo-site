## Summary

Extends the earlier time-domain-multiplexed continuous-variable cluster-state experiment by using continuous phase-feedback control to overcome long-term optical drift. The system successively generates and verifies a fully inseparable dual-rail cluster state containing more than one million optical qumodes.
