The first hardware demonstration of low-overhead qLDPC codes, using a 32-qubit superconducting processor with overlapping long-range couplers.

## Key Results
- Simultaneous measurement of all non-local weight-6 stabilizers
- Distance-4 BB code encoding four logical qubits: $(8.91 \pm 0.17)\%$ logical error per logical qubit per cycle
- Distance-3 punctured BB code encoding six logical qubits: $(7.77 \pm 0.12)\%$ logical error per logical qubit per cycle
